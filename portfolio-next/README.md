# Varaprasad Mupparaju - Portfolio (Next.js)

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content
All text lives in `app/data.js` (skills, education, projects, links).
Replace `public/resume.pdf` with a new resume any time.

## Deploy (free)
Push to GitHub, then import the repo on https://vercel.com and click Deploy.
